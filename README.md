# JS Minecraft Clone

A small minecraft clone built with JavaScript and Three.js.

Note: this is a fun side project and it may contain many bugs.

Live demo: https://akhilsirvi.github.io/js-minecraft-clone/

## what this project has

- procedural world generation from a seed
- chunk based loading and unloading
- block placing and breaking
- day and night cycle
- basic movement and physics
- inventory, hotbar, debug overlay


## control

- move: W A S D
- jump: Space
- sprint: Ctrl
- crouch: Shift
- toggle camera mode: F5
- toggle debug overlay: F3
- open chat: T

## change game settings

Edit [js/config.js](js/config.js) to tweak:

- seed
- view distance
- physics values
- day and night speed
- etc
